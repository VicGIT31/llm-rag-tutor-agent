# Leçon 2 — Les nombres (coréen, niveau A1)

## Deux séries de nombres

Le coréen a **deux séries** : les nombres sino-coréens et les nombres coréens natifs.

| | Sino-coréen | Romanisation | Natif | Romanisation |
|---|---|---|---|---|
| 1 | 일 | il | 하나 | hana |
| 2 | 이 | i | 둘 | dul |
| 3 | 삼 | sam | 셋 | set |
| 4 | 사 | sa | 넷 | net |
| 5 | 오 | o | 다섯 | daseot |
| 6 | 육 | yuk | 여섯 | yeoseot |
| 7 | 칠 | chil | 일곱 | ilgop |
| 8 | 팔 | pal | 여덟 | yeodeol |
| 9 | 구 | gu | 아홉 | ahop |
| 10 | 십 | sip | 열 | yeol |

## Quelle série utiliser ?

- **Sino-coréens** : les prix, les dates, les minutes, les numéros de téléphone. 오천 원 (ocheon won) = 5 000 wons ; 삼십 분 (samsip bun) = 30 minutes.
- **Natifs** : compter des objets ou des personnes, l'âge, et **les heures**. 세 시 (se si) = 3 heures.

Devant un compteur, les natifs 1 à 4 raccourcissent : 한 (han), 두 (du), 세 (se), 네 (ne). 사과 두 개 (sagwa du gae) = deux pommes.

Erreur fréquente : dire l'heure avec les sino-coréens. ✗ 삼 시 (sam si) → ✓ 세 시 (se si) = 3 heures.
