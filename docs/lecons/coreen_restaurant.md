# Leçon 3 — Au café et au restaurant (coréen, niveau A1)

| Coréen | Romanisation | Français |
|---|---|---|
| 어서 오세요 | eoseo oseyo | Bienvenue ! |
| 메뉴 주세요 | menyu juseyo | La carte, s'il vous plaît. |
| 물 주세요 | mul juseyo | De l'eau, s'il vous plaît. |
| 커피 한 잔 주세요 | keopi han jan juseyo | Un café, s'il vous plaît. |
| 비빔밥 두 개 주세요 | bibimbap du gae juseyo | Deux bibimbap, s'il vous plaît. |
| 얼마예요? | eolmayeyo? | Combien ça coûte ? |
| 맛있어요! | masisseoyo! | C'est délicieux ! |
| 계산해 주세요 | gyesanhae juseyo | L'addition, s'il vous plaît. |

**주세요 (juseyo)** = « donnez-moi, s'il vous plaît » : [chose] + 주세요. C'est l'équivalent du kudasai japonais.

Pour les boissons, on compte en verres ou en tasses avec 잔 (jan) et les nombres natifs : 한 잔, 두 잔.

Avant de manger : 잘 먹겠습니다 (jal meokgetseumnida) ; après : 잘 먹었습니다 (jal meogeotseumnida).
