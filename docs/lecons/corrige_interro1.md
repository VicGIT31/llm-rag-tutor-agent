## Erreurs les plus fréquentes

1. **« Dare wa kimashita ka? »** sur 12 copies : un mot interrogatif sujet prend toujours **ga** (leçon 1).
2. Oubli du **ka** final dans les questions (7 copies).
3. Mauvais ordre des mots : ✗ « kippu o kudasai ichimai » → ✓ « kippu o ichimai kudasai » : le nombre se place avant le verbe.
