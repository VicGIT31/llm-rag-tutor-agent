# Leçon 14 — La météo et les saisons (japonais, niveau A2)

## Les saisons

haru (printemps), natsu (été), aki (automne), fuyu (hiver).

## Le temps qu'il fait

| Japonais | Français |
|---|---|
| hare | beau temps |
| kumori | nuageux |
| ame | pluie |
| yuki | neige |
| kaze | vent |
| atsui | chaud (temps) |
| samui | froid (temps) |
| atatakai | doux |
| suzushii | frais (agréable) |

Attention : pour un objet ou une boisson froide, on ne dit pas samui mais **tsumetai**. Tsumetai mizu = de l'eau froide.

## Phrases modèles

- Ii tenki desu ne. = Il fait beau, n'est-ce pas ?
- Kyou wa samui desu ne. = Il fait froid aujourd'hui.
- Ashita wa ame deshou. = Demain, il pleuvra probablement.
- Kyoto no haru wa atatakai desu. Sakura ga kirei desu. = Le printemps à Kyoto est doux. Les cerisiers sont beaux.

Ne ? en fin de phrase cherche l'accord de l'interlocuteur (« n'est-ce pas ? ») ; deshou exprime une supposition.
