# Leçon 2 — En voyage au Japon (japonais, niveau A1)

## Vocabulaire du voyage

| Japonais | Kana | Français |
|---|---|---|
| eki | えき | gare |
| densha | でんしゃ | train |
| kippu | きっぷ | billet |
| hoteru | ホテル | hôtel |
| toire | トイレ | toilettes |
| mizu | みず | eau |
| yoyaku | よやく | réservation |

## Phrases utiles

| Japonais | Français |
|---|---|
| Sumimasen. | Excusez-moi. |
| Eki wa doko desu ka? | Où est la gare ? |
| Kore wa ikura desu ka? | Combien ça coûte ? |
| Mizu o kudasai. | De l'eau, s'il vous plaît. |
| Kyoto made no kippu o ichimai kudasai. | Un billet pour Kyoto, s'il vous plaît. |
| Yoyaku shite imasu. | J'ai une réservation. |
| Eigo ga hanasemasu ka? | Parlez-vous anglais ? |
| Wakarimasen. | Je ne comprends pas. |
| Arigatou gozaimasu. | Merci beaucoup. |

## Demander un lieu ou un objet

Pour demander où se trouve quelque chose : [lieu] + wa doko desu ka? Exemple : Toire wa doko desu ka? = Où sont les toilettes ?

Pour demander quelque chose : [objet] + o kudasai. La particule o marque l'objet demandé. Exemple : Kippu o kudasai. = Un billet, s'il vous plaît.
