# Leçon 8 — Les verbes en -masu (japonais, niveau A1)

## Les quatre formes polies

| Forme | Terminaison | Exemple (tabemasu, manger) |
|---|---|---|
| présent / futur | -masu | tabemasu = je mange, je mangerai |
| négatif | -masen | tabemasen = je ne mange pas |
| passé | -mashita | tabemashita = j'ai mangé |
| passé négatif | -masen deshita | tabemasen deshita = je n'ai pas mangé |

-mashou = « faisons… » : Ikimashou! = Allons-y !

## Verbes du cours

ikimasu (aller), kimasu (venir), kaerimasu (rentrer), tabemasu (manger), nomimasu (boire), mimasu (regarder), yomimasu (lire), kikimasu (écouter), shimasu (faire), okimasu (se lever), nemasu (se coucher).

## Les particules qui accompagnent le verbe

- **o** : l'objet de l'action. Sushi o tabemasu. = Je mange des sushis.
- **e** ou **ni** : la direction. Gakkou e ikimasu. = Je vais à l'école.
- **de** : le lieu de l'action, ou le moyen. Toshokan de hon o yomimasu. = Je lis un livre à la bibliothèque. Densha de ikimasu. = J'y vais en train.
- **ni** : un moment précis. Shichi-ji ni okimasu. = Je me lève à 7 h. Pas de ni avec mainichi (tous les jours), kyou ou ashita.

Erreur fréquente : ✗ « Toshokan ni hon o yomimasu » → ✓ « Toshokan **de** hon o yomimasu » (on agit dans un lieu : de).
