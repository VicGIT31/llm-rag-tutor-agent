# Leçon 11 — La forme en -te (japonais, niveau A2)

## Former le -te

**Groupe 2** (verbes en -eru / -iru) : on remplace -ru par -te. taberu → tabete, miru → mite, okiru → okite.

**Groupe 1** : la terminaison change selon la dernière syllabe.

| Fin du verbe | Forme en -te | Exemple |
|---|---|---|
| -u, -tsu, -ru | -tte | kau → katte, matsu → matte, kaeru → kaette |
| -mu, -bu, -nu | -nde | nomu → nonde, asobu → asonde, shinu → shinde |
| -ku | -ite | kaku → kaite, kiku → kiite |
| -gu | -ide | oyogu → oyoide |
| -su | -shite | hanasu → hanashite |

Exception du groupe 1 : **iku → itte** (et non « iite »).

**Groupe 3** (irréguliers) : suru → shite, kuru → kite.

Piège : **kaeru** (rentrer) est du groupe 1 malgré sa terminaison en -eru : ✗ « kaete » → ✓ « kaette ».

## Trois usages

- **-te kudasai** : demander poliment. Chotto matte kudasai. = Attendez un instant, s'il vous plaît.
- **-te imasu** : une action en cours. Ima terebi o mite imasu. = Je suis en train de regarder la télé.
- **-te mo ii desu ka** : demander la permission. Shashin o totte mo ii desu ka? = Je peux prendre une photo ?
