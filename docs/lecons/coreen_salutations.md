# Leçon 1 — Saluer et se présenter (coréen, niveau A1)

| Coréen | Romanisation | Français |
|---|---|---|
| 안녕하세요 | annyeonghaseyo | bonjour |
| 감사합니다 | gamsahamnida | merci |
| 네 | ne | oui |
| 아니요 | aniyo | non |
| 개 | gae | chien |
| 고양이 | goyangi | chat |

Pour se présenter : 저는 카미유입니다 (jeoneun Kamiyu-imnida) = Je suis Camille.

La particule 는 / 은 (neun après une voyelle, eun après une consonne) marque le thème, comme wa en japonais.
